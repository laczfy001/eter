Free radio playout

Run your station on air, around the clock

Éter is radio playout and automation software for Windows and Linux: three players with smart automatic mixing, a cartwall, a music scheduler, a mix editor, built-in Icecast / Shoutcast streaming, song requests from your website, MIDI control and a backup playout – in one desktop application.

Everything a station needs

From the first song in the morning to the news at the top of every hour, Éter plays, mixes and schedules by itself – or lets you take over at any moment.

Three players, automatic mixing

Players A, B and C, so a song, a jingle and the next song can sound at once. The smart automatic mix reads the waveform: fade-outs and sudden endings, soft and strong intros, clashing tempos or keys.

Mix editor

Shape any transition on a timeline: mix point, fade curves, cue-in, intro, voice tracks and music ducking, with preview. Lay a jingle over a crossfade so three items play together.

On time, every time

Before every fixed-time item the playlist shows how much is missing or over and suggests tracks to add, drop or swap – and in automatic mode it adjusts by itself, up to 30 minutes ahead.

Music scheduler

Clocks built from categories, fixed elements and fills; week grids by date period; artist and title separation, energy, tempo, dayparts, vocal rules and harmonic mixing on the Camelot wheel.

Library and analysis

An SQLite library with categories, folder import and an item editor. Background analysis fills in tempo and key at the lowest priority; missing files are found well before they go on air.

Cartwall and live streams

Coloured walls of instant-start buttons on their own output. Icecast and Shoutcast streams can be playlist items with a planned length and reconnect by themselves when they drop.

Song requests from your website

Now playing, Up next, Most played and Song request widgets with the WordPress plugin, or for any PHP site with Éter Web. The studio computer never has to be reachable from the internet.

Now playing and Icecast

The title on air goes to a text file from a template for your stream encoder or caption, and Éter can update the Icecast server's metadata directly. A program logger records the output into hourly MP3 files.

Built-in stream encoders

Stream to Icecast or Shoutcast in MP3 or Ogg Vorbis, several encoders at once, from the main output or a sound card input. Titles, automatic reconnect and the outgoing bandwidth at a glance.

MIDI control

Use a mixer such as the RØDECaster Pro, or any MIDI controller. Learn mode: pick an action, move a button or fader. Buttons start and stop; faders set volumes or work as fader start.

Remote editing

Edit the live playlist of the playout computer from anywhere on the network, with the full Mix editor and uploads. Users get their own passwords and rights; passwords never cross the network.

Backup playout

A second computer keeps a copy of the whole database and follows what is on air. If the main computer stops answering, the backup continues the same item – and hands it back later.

External SQL server

MySQL or MariaDB as the main store, with a local copy as a reserve, so the broadcast never depends on the network. Database export and import for backups and moving to another computer.

A player that tells you what's next

  • Waveform with the intro countdown and the automatic mix point to the next player.
  • Artist info from MusicBrainz, Wikipedia and TheAudioDB: photo, country, years, genre and biography.
  • Red countdown in the last 10 seconds, counting to the mix point in automatic mode.
  • Every channel – the three players, preview and cartwall – can go to its own sound card.

See the mix before it goes on air

  • Every threshold of the automatic mix is adjustable, with a live diagram of two example items.
  • Save settings as mix templates and switch between them.
  • Jingles, ads, news and voice tracks follow each other back to back, with the silence cut.
  • A dead-air guard moves on when the item on air stays silent.

Make it yours

  • Five colour schemes – Éter dark, Graphite, Midnight blue, High contrast and Light.
  • A theme editor for every base colour; save your schemes by name, export and import them.
  • Hide the tabs you don't use, resize every column, and set the interface size.
  • English and Hungarian interface.

Install

Download, unpack and start – no installer, no account. Audio files are never copied or modified; the library only refers to them.

Windows

Unpack Eter-…-win64.zip anywhere and start eter.exe (64-bit Windows 10 or 11). Eter-szerkeszto.cmd starts the remote editor, Eter-tartalek.cmd the backup playout.

The program is not code-signed, so Windows may show an “unknown publisher” warning on first start.

Linux

64-bit Linux with glibc 2.39 or newer (Ubuntu 24.04 and later) and PipeWire, PulseAudio, ALSA or JACK.

chmod +x Eter-*-x86_64.AppImage
./Eter-*-x86_64.AppImage

Website widgets

Éter Radio for WordPress (eter-radio.zip): blocks and shortcodes for now playing, up next, most played and song requests.

Éter Web (eter-web.zip): the same widgets for any PHP web host, embedded with one script line.
